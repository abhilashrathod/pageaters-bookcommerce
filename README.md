# Pageaters

Pageaters was an online bookstore in India (2022–2024). This repository rebuilds its storefront, admin and API
as a Turborepo monorepo and runs it as a sandboxed portfolio demo. It is not a live store.

> Work in progress: the migration plan is in [`PLAN.md`](./PLAN.md). A full README with architecture, live links
> and local setup arrives at the end of that plan.
